# Arquivo — trilhas de código

As trilhas Front-end, Back-end e Full-Stack e as cinco aulas escritas para
elas saíram do currículo na virada para trilhas de entrega com IA
(`docs/superpowers/specs/2026-10-28-studymaps-ia-design.md`, §12.3).

Elas **não foram apagadas**: são o único conteúdo real escrito antes da
virada e podem voltar como material de consulta. Continuam compilando e
sendo checadas pelo `tsc`, de propósito — é assim que a gente garante que
não apodreçam em silêncio.

O que não acontece mais: nada aqui é importado por `src/content/index.ts`,
então não aparece no app. As rotas antigas (`/roadmap/frontend` e afins)
redirecionam para a trilha atual.
